Mesin kecerdasan

Ekstraksi & embedding memori. Mode auto memakai Ollama bila menyala; tanpa model pun Memoria tetap bekerja (heuristik → hasil masuk antrian tinjau). Perubahan langsung aktif tanpa restart.
Endpoint OpenAI-compatible — LM Studio (localhost:1234), llama.cpp, vLLM, atau cloud. Catatan privasi: memakai endpoint cloud berarti konten sesi keluar dari mesin ini.
